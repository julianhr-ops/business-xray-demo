# BUSINESS X-RAY: live demo

Static build of the BUSINESS X-RAY explorer, served by GitHub Pages: https://julianhr-ops.github.io/business-xray-demo/

It reads a dated snapshot of official Colombian data (Supersociedades and Superfinanciera on datos.gov.co, CC BY-SA 4.0; DANE IPC). Queries run in your browser with DuckDB-WASM. There is no server and there are no credentials.
